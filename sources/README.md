# Fonti Archiviate

Questa directory contiene copie locali di articoli, sentenze e screenshot usati come fonti per il grafo SCU.

## Struttura

```
sources/
├── articoli/      # Screenshot/PDF di articoli giornalistici
├── sentenze/      # Documenti giudiziari pubblici
└── screenshot/    # Catture schermo di pagine web
```

## Convenzioni di naming

```
YYYY-MM-DD_fonte_argomento.ext
```

Esempi:
- `2023-05-15_corriere-operazione-filo-arianna.pdf`
- `2021-01-20_dda-reggio-calabria-faust-sentenza.pdf`
- `2025-11-19_tgla7-operazione-escape.png`

## Perché archiviare?

Le fonti online possono scomparire. Questa cartella garantisce la tracciabilità delle informazioni senza dipendere da Wayback Machine o cache esterne.
